When I ask you to set it to "done", also write a short summary of the work in the "### Outcome" section of the issue; do not write the Outcome before that. - review your changes
- refactor
- commit
- push
- update the PWA online: make sure that the GitHub Pages deployment is successful and that the online URL shows the new version
